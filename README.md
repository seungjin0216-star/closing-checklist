# 마감체크리스트 (백석직영점)

**바로가기: https://seungjin0216-star.github.io/closing-checklist/**

각자 폰으로 위 링크에 접속해서 마감 체크리스트를 체크하고, 다 체크하면 "완료하기"를 누르는 웹앱입니다.

## 구조 (v4)

화면(프론트엔드)과 데이터 저장(백엔드)이 분리되어 있습니다.

- **화면**: `index.html` — 순수 HTML/CSS/JS로 직접 만든 화면 (기존 "백석 발주" 앱과 같은 스타일). **GitHub Pages**로 호스팅됩니다.
- **데이터 저장**: `Code.gs` — Google Apps Script. 두 가지만 담당합니다.
  - `GET ?action=monthly&month=YYYY-MM` (JSONP) — 이번 달 월간청소 상태 조회 (공유)
  - `POST` (JSON body) — 완료 기록 저장, 월간청소 체크 저장

### v4에서 바뀐 점: "각자 폰 안에서만 체크"

이전 버전은 체크할 때마다 실시간으로 구글시트에 저장되고 여러 폰이 그 상태를 공유했습니다. 이 방식은 여러 명이 동시에 같은 항목(특히 아코디언 그룹)을 빠르게 체크할 때 요청이 서로 겹쳐서 일부만 반영되거나 다시 켜지는 문제가 있었습니다.

v4부터는:
- **필수 마감(채우기/청소/정기청소/마지막확인) 체크는 전부 이 폰 안에서만 처리**됩니다. 서버 호출이 없어서 즉시 반응하고, 충돌도 생기지 않습니다.
- 새로고침해도 그날 안에는 체크 내용이 유지되도록 브라우저에 저장해둡니다 (기기 저장공간을 완전히 정리하거나 브라우저 데이터를 삭제하면 사라질 수 있습니다).
- **"완료하기"를 누른 순간에만 딱 한 번** 구글시트(`DayStatus` 시트)에 "그날 완료됨 + 시각"이 기록됩니다. 여러 명이 각자 폰으로 완료해도 각각 새 줄로 쌓이는 것뿐이라 문제가 없습니다.
- **월간청소만 예외적으로 공유**됩니다 (`MonthlyStatus` 시트). 한 달에 한 번만 하면 되는 항목이라 "이미 누가 했는지" 서로 볼 수 있어야 의미가 있고, 자주 건드리지 않아 충돌 위험도 낮습니다.
- 구글시트 쓰기 작업은 `LockService`로 잠가서, 여러 요청이 겹쳐도 한 번에 하나씩만 처리되도록 했습니다 (월간청소, 완료 기록 모두 해당).

## 코드 수정 후 반영하는 법

### 화면(index.html) 수정
GitHub에서 `index.html`을 고치고 main 브랜치에 커밋하면, GitHub Pages가 1분 이내에 자동으로 새 버전을 배포합니다.

### 데이터 로직(Code.gs) 수정
1. [Apps Script 프로젝트](https://script.google.com/u/0/home/projects/1HbUhlEPVUDPdSE1bDxnWVswomvd7EVspwrBvZCu6GK8qwPlyDzSL6mhe/edit) 접속 (구글 계정 로그인 필요)
2. `Code.gs` 내용을 GitHub 저장소의 최신 `Code.gs`로 교체하고 저장
3. 우측 상단 **배포 → 배포 관리 → 수정(연필 아이콘) → 버전: 새 버전 → 배포**
4. 배포 ID/URL은 그대로 유지되므로 (`index.html`의 `GAS_URL`을 바꿀 필요 없음) 재배포만 하면 끝

## 항목 추가/수정하는 법

`Code.gs`(월간청소 `MONTHLY_ITEMS`)와 `index.html`(`FILL_SEQUENCE`, `CLEAN_ITEMS`, `WEEKLY_ITEMS`, `MONTHLY_ITEMS`, `FINAL_ITEMS`) 양쪽에 항목 배열이 들어있습니다. 필수 마감 항목은 이제 `index.html`에만 있으면 되고(서버에 안 보내므로), 월간청소 항목만 두 파일 모두 같은 내용으로 맞춰야 합니다. `id` 값은 한번 배포된 뒤에는 되도록 바꾸지 않는 게 좋습니다.

## 기록 확인

Google Sheets "마감체크리스트_백석"을 열면 됩니다. `DayStatus` 시트에는 날짜별 완료 기록(여러 명이 각자 완료하면 그만큼 여러 줄)이, `MonthlyStatus` 시트에는 월간청소 체크 현황이 쌓입니다.
