# 마감체크리스트 (백석직영점)

각자 폰으로 접속해서 마감 체크리스트를 체크하고, 다 체크하면 "완료하기"를 누르는 웹앱입니다.
기록은 Google Sheets에 자동 저장되어 나중에 누가 뭘 체크했는지 확인할 수 있습니다.

## 구성

- `Code.gs` — 서버 로직 (체크 항목 정의, 시트 읽기/쓰기, 완료 처리)
- `Index.html` — 화면 (모바일 최적화, 이름 입력 + 체크리스트 + 완료 버튼)

체크 항목은 3그룹입니다.
- **필수 마감** (10개) — 누구나 매일 확인
- **마감 후 추가로 확인** (7개) — 직원 위주지만 알바도 화면에서 그대로 보이고 체크 가능
- **재료준비** (17개, 추가 확인 섹션 안의 접이식 하위 목록)

"완료하기" 버튼은 34개 항목을 전부 체크해야 눌러집니다. 완료하면 그날 참여자 이름과 시각이 기록되고, 실수했을 때는 "완료 취소"로 되돌릴 수 있습니다.

## 배포 방법 (약 5분, 구글 계정만 있으면 됨)

1. **Google Sheets**에서 새 스프레드시트를 만듭니다. (이름 예: `마감체크리스트_백석`)
2. 상단 메뉴에서 **확장 프로그램 → Apps Script** 클릭
3. 열린 편집기에서 기본 `Code.gs` 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 파일 목록의 `+` → **HTML** 선택 → 파일명을 정확히 `Index` 로 저장 (자동으로 `Index.html`이 됩니다)
5. 기본 내용을 지우고 이 폴더의 `Index.html` 내용을 붙여넣습니다.
6. 저장(Ctrl+S / Cmd+S) 후 우측 상단 **배포 → 새 배포**
7. 유형 선택에서 톱니바퀴 → **웹앱** 선택
8. 설정:
   - 실행 계정: **나 (본인 구글 계정)**
   - 액세스 권한: **전체** (링크만 있으면 로그인 없이 접속 가능)
9. **배포** 클릭 → 권한 승인(처음 한 번은 "고급" → "이동" 눌러야 할 수 있음)
10. 나온 **웹앱 URL**을 복사해서 카카오톡 단체방 등에 공유하면, 각자 폰에서 그 링크로 바로 접속해 체크할 수 있습니다.

## 코드 수정 후 재배포

`Code.gs` / `Index.html` 내용을 나중에 수정하면, Apps Script 편집기에서 **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전 → 배포** 를 눌러야 실제 웹앱에 반영됩니다. (저장만 하고 재배포를 안 하면 기존 링크는 이전 버전으로 남아있음)

## 항목 수정하는 법

`Code.gs` 맨 위 `BASE_ITEMS` / `EXTRA_ITEMS` / `INGREDIENT_ITEMS` 배열의 `label` 값만 바꾸거나, 줄을 추가/삭제하면 됩니다. `id` 값은 한번 배포된 뒤에는 되도록 바꾸지 않는 게 좋습니다 (과거 기록과 연결이 끊길 수 있음).

## 기록 확인

화면 하단 "전체 기록 (구글시트) 보기" 링크를 누르면 원본 스프레드시트로 이동합니다. `Log` 시트에는 날짜별·항목별 체크 기록(누가, 언제)이, `DayStatus` 시트에는 날짜별 완료 여부와 참여자 목록이 쌓입니다.
