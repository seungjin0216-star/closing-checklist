# 기준사진 — ❓ 를 누르면 나오는 사진

마감체크리스트에서 ❓ 를 누르면 글과 함께 여기 사진이 뜹니다.

## 넣는 법

```
① 사진을 이 폴더에 넣습니다
② index.html 의 기준표 에 파일 이름을 적습니다

   gm1: {
     글: '...',
     사진: ['gm1-1.jpg', 'gm1-2.jpg'],
   }
```

**이름은 「항목id-번호.jpg」로 맞춥니다.** 어느 항목 것인지 바로 알 수 있게.

## ⚠️ 사진을 줄여서 넣으십시오

```
폰 카메라 원본은 3~5MB 입니다. 매장 와이파이에서 한참 안 뜹니다.
긴 쪽 1200px · 300KB 이하로 줄입니다.
```

AI 가 샌드박스에서 줄일 수 있습니다 (Pillow 가 깔려 있습니다).

```python
from PIL import Image
im = Image.open('원본.jpg'); im.thumbnail((1200,1200))
im.save('gm1-1.jpg', 'JPEG', quality=82, optimize=True)
```

맥에서 직접 줄이려면 — 터미널에 이렇게 칩니다.

```bash
cd ~/웹앱프로젝트/마감체크리스트/기준사진
sips -Z 1200 gm1-1.jpg gm1-2.jpg
```

⚠️ `sips` 는 맥에 원래 있는 도구입니다. **원본을 덮어씁니다.**

## 지금 있는 것

| 파일 | 항목 | 무엇을 보여주나 | 크기 |
|---|---|---|---|
| `gm1-1.jpg` | 고기정리 | 냉장고 칸에 바구니가 들어간 모습 — 선입선출·얼지 않게 | 900×1200 · 184KB |
| `gm1-2.jpg` | 고기정리 | 곱창을 바구니에 펴 담은 모습 — 날짜·등급별 분배 | 900×1200 · 180KB |

⚠️ **사진이 없어도 글은 그대로 뜹니다.** 그 자리만 조용히 빕니다.

## 🔴 사진을 어떻게 여기까지 가져왔나 (2026-09-28)

사장님이 대화에 올린 사진은 **AI 샌드박스에서 못 집습니다.** uploads 폴더에도 안 들어옵니다.
맥의 임시 폴더에만 있습니다.

```
/private/tmp/claude-501/-private-var-empty/<대화id>/images/3.jpg
```

**Finder 를 직접 조작해 가져왔습니다.** 그때 걸린 것들:

```
⚠️ 배경(app_*) 모드에서는 Return 키가 안 갑니다 → 화면 제어(display-scope)가 필요
⚠️ Cmd+C / Cmd+V 단축키가 안 먹습니다 → 편집 메뉴에서 「복사」·「붙여넣기」를 직접 클릭
⚠️ Cmd+Shift+G 도 안 열립니다 → 「이동」 메뉴를 클릭하거나, 뒤로/앞으로 버튼으로 오갑니다
⚠️ 한글 경로는 타이핑이 안 들어갑니다 → 사이드바·폴더를 클릭해서 찾아갑니다
```

**다음에 사진을 넣을 때는 이 순서가 빠릅니다.**

```
① Finder 「이동 → 폴더로 이동」 으로 위 임시 경로 열기 (영문이라 타이핑 됨)
② 파일 선택 → 편집 메뉴 → 「N개의 항목 복사」
③ 뒤로/앞으로 버튼으로 기준사진 폴더까지 이동
④ 편집 메뉴 → 「N개의 항목 붙여넣기」
⑤ 나머지(이름 변경·크기 축소)는 AI 가 bash 로 처리
```
