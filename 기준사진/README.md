# 기준사진 — ❓ 를 누르면 나오는 사진

마감체크리스트에서 ❓ 를 누르면 글과 함께 여기 사진이 뜹니다.

## 넣는 법

```
① 사진을 이 폴더에 넣습니다
② index.html 의 기준표 에 파일 이름을 적습니다

   gm1: {
     글: '...',
     사진: ['gm1-1.jpg', 'gm1-2.jpg'],
   }
```

**이름은 「항목id-번호.jpg」로 맞춥니다.** 어느 항목 것인지 바로 알 수 있게.

## ⚠️ 사진을 줄여서 넣으십시오

```
폰 카메라 원본은 3~5MB 입니다. 매장 와이파이에서 한참 안 뜹니다.
긴 쪽 1200px · 300KB 이하로 줄이십시오.
```

맥에서 줄이는 법 — 터미널에 이렇게 칩니다.

```bash
cd ~/웹앱프로젝트/마감체크리스트/기준사진
sips -Z 1200 gm1-1.jpg gm1-2.jpg
```

⚠️ `sips` 는 맥에 원래 있는 도구입니다. 따로 깔 것 없습니다.
⚠️ **원본을 덮어씁니다.** 원본을 남기려면 먼저 다른 곳에 복사해 두십시오.

## 지금 있어야 할 것

| 파일 | 항목 | 무엇을 보여주나 |
|---|---|---|
| `gm1-1.jpg` | 고기정리 | 냉장고 칸에 바구니가 들어간 모습 — 선입선출·얼지 않게 |
| `gm1-2.jpg` | 고기정리 | 곱창을 바구니에 펴 담은 모습 — 날짜·등급별 분배 |

⚠️ **사진이 없어도 글은 그대로 뜹니다.** 그 자리만 조용히 빕니다.
